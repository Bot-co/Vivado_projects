## 🎯 Repository Overview
This repository contains structural logic designs and hardware block implementations, prioritizing high-performance unit architecture. The projects range from foundational arithmetic logic units (ALUs) to specialized approximate computing hardware, complete with behavioral simulations, and timing/power analysis reports.

## 📁 Key Projects Included

### 1. Advanced Arithmetic Adders (16-bit & 32-bit)
*   **Carry Lookahead Adders (CLA)**
*   **Carry Select Adders**
*   **Conditional Sum Adders:** Includes a specific 16-bit block-ripple architecture built by splitting the 16 bits into 4-bit conditional sum building blocks and rippling the carry between them.
*   **Ripple Carry Adders** the design of this adder is fully parametrized which is highly useful when scaling the design.
  
### 2. High-Performance Multipliers
*   **Booth Multiplier**
*   **Array Multiplier**

### 3. Approximate Arithmetic Unit for Edge AI
*This design is a part of what i have created in my internship period titled  **FPGA Implementation of  Approximate Arithmetic Unit for AI inference** it includes*
*   A research-focused design exploring hardware efficiency for AI inference.
*   Focuses on the tradeoffs between calculation accuracy and power consumption for edge systems.
